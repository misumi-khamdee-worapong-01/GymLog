# 🏋️ GymLog — แอปวางแผนและบันทึกการเวทเทรนนิ่ง

เว็บแอปสำหรับ **วางแผนโปรแกรมเทรน** และ **บันทึกผลการออกกำลังกาย** พร้อมสรุปสถิติและติดตามความก้าวหน้า
เขียนด้วย Flask ไฟล์เดียว (`app.py`) + Tailwind CSS ผ่าน CDN + ฐานข้อมูล SQLite ที่สร้างเองอัตโนมัติ

ข้อมูลทั้งหมดเก็บอยู่บนเครื่องคุณในไฟล์ `gymlog.db` ไม่มีการส่งข้อมูลออกไปที่ไหน

---

## 📋 สิ่งที่ต้องมี

- Python 3.9 ขึ้นไป
- Flask 3.x
- อินเทอร์เน็ตตอนเปิดหน้าเว็บ (เพราะ Tailwind CSS และฟอนต์โหลดจาก CDN)

---

## 🚀 การติดตั้งและรัน

### รันเลย (โปรเจกต์นี้มี virtual environment เตรียมไว้แล้ว)

```bash
.venv/bin/python app.py
```

### หรือติดตั้งใหม่ตั้งแต่ต้น

```bash
python3 -m venv .venv
.venv/bin/pip install flask
.venv/bin/python app.py
```

เมื่อรันสำเร็จจะเห็นข้อความ:

```
GymLog พร้อมใช้งานที่ http://127.0.0.1:5001  (ฐานข้อมูล: .../gymlog.db)
```

เปิดเบราว์เซอร์ไปที่ **http://127.0.0.1:5001**

> **ทำไมถึงใช้พอร์ต 5001?** บน macOS พอร์ต 5000 มักถูก AirPlay Receiver จองไว้
> เปลี่ยนพอร์ตได้ด้วยตัวแปรสภาพแวดล้อม `PORT`:
>
> ```bash
> PORT=8000 .venv/bin/python app.py
> ```

ครั้งแรกที่รัน แอปจะสร้างไฟล์ `gymlog.db` พร้อมข้อมูลตั้งต้นให้อัตโนมัติ:
ท่าออกกำลังกาย 18 ท่า และแผนตัวอย่าง 3 แผน (Push Day / Pull Day / Leg Day)

หยุดเซิร์ฟเวอร์ด้วย `Ctrl + C`

## 📖 วิธีใช้งาน

### ขั้นที่ 1 — เตรียมคลังท่า (เมนู "คลังท่า")

ระบบมีท่าเริ่มต้นให้ 18 ท่าแล้ว ถ้าอยากเพิ่มท่าของตัวเอง:

1. กรอก **ชื่อท่า** (ห้ามซ้ำกับท่าที่มีอยู่)
2. เลือก **กลุ่มกล้ามเนื้อ** — อก / หลัง / ขา / ไหล่ / แขน / แกนกลาง / คาร์ดิโอ
3. ระบุ **อุปกรณ์** และ **โน้ต** (เทคนิคหรือข้อควรระวัง) ตามต้องการ
4. กด **เพิ่มท่า**

ค้นหาท่าด้วยช่องค้นหา หรือกรองตามกลุ่มกล้ามเนื้อได้จากดรอปดาวน์ด้านขวา
คอลัมน์ "ใช้แล้ว" บอกว่าท่านั้นถูกบันทึกไปแล้วกี่เซ็ต

> ⚠️ การลบท่าจะลบเซ็ตที่บันทึกไว้ของท่านั้นทั้งหมดด้วย

---

### ขั้นที่ 2 — วางแผนการเทรน (เมนู "แผนเทรน")

**สร้างแผนใหม่:**

1. กรอกชื่อแผน เช่น `Upper Body A`
2. เลือกวันในสัปดาห์ที่ตั้งใจจะเทรน (ไม่บังคับ)
3. ใส่คำอธิบายหรือเป้าหมายของแผน
4. กด **สร้างแผน** → ระบบจะพาเข้าหน้ารายละเอียดแผนทันที

**เพิ่มท่าเข้าแผน** (ในหน้ารายละเอียดแผน) กรอกฟอร์มด้านล่างตาราง:

| ช่อง | ความหมาย |
|---|---|
| ท่าออกกำลังกาย | เลือกจากคลังท่า |
| เซ็ต | จำนวนเซ็ตที่ตั้งใจทำ |
| ครั้ง | จำนวนครั้งต่อเซ็ต (reps) |
| น้ำหนัก | น้ำหนักเป้าหมาย (กก.) |
| พัก | เวลาพักระหว่างเซ็ต (วินาที) |

ด้านบนจะสรุปให้ว่าแผนนี้มีกี่ท่า กี่เซ็ต และ **ปริมาณเป้าหมาย** รวมกี่กิโลกรัม

---

### ขั้นที่ 3 — เริ่มเทรนและบันทึกผล

**วิธีที่ 1 — เริ่มจากแผน (แนะนำ)**

กดปุ่ม **▶ เริ่มเทรนตามแผนนี้** ในหน้าแผน หรือปุ่ม **เริ่มเลย** ที่หน้าภาพรวม

ระบบจะสร้างเซสชันใหม่ **พร้อมเซ็ตทั้งหมดตามแผน** ที่กรอกน้ำหนักและจำนวนครั้งเป้าหมายไว้ให้ล่วงหน้า
โดยทุกเซ็ตเริ่มต้นที่สถานะ **"ยังไม่ทำ"**

**วิธีที่ 2 — บันทึกเซสชันเปล่า**

ที่เมนู "บันทึก" กรอกชื่อ วันที่ ระยะเวลา แล้วกด **+ สร้างเซสชัน** จากนั้นค่อยเพิ่มเซ็ตเองทีละท่า

**ในหน้าเซสชัน:**

- แต่ละแถวคือหนึ่งเซ็ต แก้ **น้ำหนัก / จำนวนครั้ง / RPE** ได้โดยตรง แล้วกด **บันทึก**
  (กดบันทึกแล้วเซ็ตนั้นจะถูกนับว่า "ทำแล้ว" อัตโนมัติ และแถวจะเปลี่ยนเป็นสีเขียว)
- ปุ่ม **✓ ทำแล้ว / ยังไม่ทำ** ใช้สลับสถานะโดยไม่แก้ตัวเลข
- ปุ่ม **✕** ลบเซ็ตนั้นทิ้ง
- ฟอร์มด้านล่างสุดใช้ **เพิ่มเซ็ต** โดยระบุ "จำนวนเซ็ต" เพื่อเพิ่มหลายเซ็ตพร้อมกันในครั้งเดียวได้
- กล่องขวาบนใช้แก้ชื่อ วันที่ ระยะเวลา และโน้ตความรู้สึกของวันนั้น

> 💡 **RPE** (Rate of Perceived Exertion) คือระดับความหนักที่รู้สึก 0–10
> เช่น 8 = เหลือแรงทำได้อีกประมาณ 2 ครั้ง ใส่ 0 ได้ถ้าไม่อยากบันทึก

---

### ขั้นที่ 4 — ติดตามผล

**หน้าภาพรวม** แสดง:

- **เซสชันทั้งหมด** — จำนวนครั้งที่เทรนสะสม
- **ปริมาณรวม** — ผลรวมของ `น้ำหนัก × จำนวนครั้ง` ทุกเซ็ตที่ทำแล้ว
- **สัปดาห์นี้** — จำนวนครั้งและปริมาณตั้งแต่วันจันทร์ของสัปดาห์ปัจจุบัน
- **สตรีคต่อเนื่อง** — จำนวนวันที่เทรนติดต่อกัน (ยังไม่เทรนวันนี้จะยังไม่ตัดสตรีค)
- กราฟแท่งปริมาณการเทรน 14 วันล่าสุด (ชี้เมาส์ที่แท่งเพื่อดูตัวเลข)
- สัดส่วนกลุ่มกล้ามเนื้อที่เทรนใน 30 วันล่าสุด — ใช้เช็กว่าเทรนสมดุลหรือไม่

**หน้าความก้าวหน้า** เลือกท่าที่สนใจ แล้วดู:

- **น้ำหนักสูงสุด** ที่เคยยกได้ (PR)
- **เซ็ตหนักสุด** — ปริมาณสูงสุดในเซ็ตเดียว
- **ปริมาณสะสม** และ **จำนวนเซ็ตทั้งหมด** ของท่านั้น
- กราฟปริมาณต่อเซสชัน และตารางประวัติ 20 ครั้งล่าสุด (กด "เปิด →" เพื่อย้อนดูเซสชันนั้น)

## 🧮 การคำนวณที่ควรรู้

- **ปริมาณ (Volume)** = `น้ำหนัก × จำนวนครั้ง` รวมทุกเซ็ต — ตัวชี้วัดหลักของภาระการเทรน
- นับ **เฉพาะเซ็ตที่ติ๊กว่า "ทำแล้ว"** เท่านั้น เซ็ตที่วางแผนไว้แต่ยังไม่ทำจะไม่ถูกนับ
- ท่าบอดี้เวทอย่างพูลอัพให้ใส่น้ำหนักเป็น `0` หรือใส่เฉพาะน้ำหนักถ่วงที่เพิ่ม
- ท่าที่วัดเป็นเวลา เช่น แพลงก์ หรือคาร์ดิโอ ให้บันทึกวินาที/นาทีลงในช่อง "จำนวนครั้ง"

## 🗄️ ฐานข้อมูล

ไฟล์ `gymlog.db` (SQLite) อยู่ในโฟลเดอร์เดียวกับ `app.py` มี 5 ตาราง:

| ตาราง | เก็บอะไร |
|---|---|
| `exercises` | คลังท่าออกกำลังกาย |
| `plans` | แผนการเทรน |
| `plan_items` | ท่าและเป้าหมายในแต่ละแผน |
| `workouts` | เซสชันการเทรนแต่ละครั้ง |
| `workout_sets` | เซ็ตที่บันทึก (น้ำหนัก ครั้ง RPE สถานะ) |

- **สำรองข้อมูล:** คัดลอกไฟล์ `gymlog.db` เก็บไว้
- **ล้างข้อมูลทั้งหมดเริ่มใหม่:** ลบไฟล์ `gymlog.db` แล้วรันแอปใหม่ ระบบจะสร้างพร้อมข้อมูลตั้งต้นให้อีกครั้ง

```bash
rm gymlog.db && .venv/bin/python app.py
```

## 🛠️ การแก้ปัญหา

| อาการ | สาเหตุและวิธีแก้ |
|---|---|
| `Address already in use` | มีโปรแกรมอื่นใช้พอร์ตอยู่ ให้รันด้วยพอร์ตอื่น เช่น `PORT=8000 .venv/bin/python app.py` |
| `ModuleNotFoundError: No module named 'flask'` | ยังไม่ได้ติดตั้ง Flask หรือรันด้วย Python ตัวอื่น ให้ใช้ `.venv/bin/python` หรือติดตั้งด้วย `pip install flask` |
| หน้าเว็บขึ้นเป็นข้อความล้วน ไม่มีสี | เครื่องต่อเน็ตไม่ได้ Tailwind CSS จึงโหลดจาก CDN ไม่สำเร็จ |
| เพิ่มท่าไม่ได้ ขึ้นว่า "มีท่าชื่อนี้อยู่แล้ว" | ชื่อท่าต้องไม่ซ้ำ ลองค้นหาในคลังท่าก่อน |
| ปริมาณรวมเป็น 0 ทั้งที่บันทึกเซ็ตแล้ว | เซ็ตยังอยู่สถานะ "ยังไม่ทำ" ให้กดปุ่ม **บันทึก** หรือ **✓ ทำแล้ว** ในแต่ละเซ็ต |

## 📁 โครงสร้างโปรเจกต์

```
website/
├── app.py       # ทั้งแอปอยู่ในไฟล์เดียว (routes + schema + เทมเพลต HTML)
├── README.md    # ไฟล์นี้
├── gymlog.db    # ฐานข้อมูล สร้างอัตโนมัติตอนรันครั้งแรก
└── .venv/       # virtual environment
```

ภายใน `app.py` แบ่งเป็นส่วน ๆ ตามคอมเมนต์: `database` → `helpers` → `routes` → `templates`
เทมเพลตทั้ง 8 หน้าเก็บเป็นสตริงและโหลดผ่าน Jinja `DictLoader` จึงยังคงเขียนแบบ `extends` ได้ตามปกติ
